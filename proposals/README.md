# Proposals

Designs that aren't built yet. Each says what problem it solves, what evidence it rests on
(a benchmark run or narrative), what it costs, and what's still open.

- [Correctness receipt](correctness-receipt.md): answer numeric questions twice by independent
  routes, and mark the reply verified only when the two agree.
- [Audit checker](audit-checker.md): a hash-chained record of every action behind an answer,
  checks for network or out-of-workspace attempts, and `/how` to show users the steps.
