# Model splits 

This document describes the model splitting responsibilities 

  +-----------+---------------------------------------------------------------------------+
  |    Who    |                                   What                                    |
  +-----------+---------------------------------------------------------------------------+
  | Our team  | Anything that changes the world (send, book, post, move); the trusted     |
  |           | list of packages and sources; masking/privacy stuff.                      |
  +-----------+---------------------------------------------------------------------------+
  |           | Making and deleting sandboxes and choosing what each can reach;           |
  | Builder   | connectors and fields; adding packages and tools from the trusted         |
  |           | list (eg: OCR, speech); asking the team for new actions; general creative |
  |           | work on public data (today's antigravity role)                            |
  +-----------+---------------------------------------------------------------------------+
  | Sandbox   | Views, definitions, chains, and scripts (try-out scripts, glue between    |
  | Claude    | steps, charts), using only what the sandbox may already import. Idli runs |
  |           |  them on real data                                                        |
  +-----------+---------------------------------------------------------------------------+
