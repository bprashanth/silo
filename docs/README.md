# Docs

Read in this order:

1. [goals.md](goals.md): what the core is, as built and tested, with what is built and what isn't.
2. [cli.md](cli.md): every term and command, with an example.
3. [decisions.md](decisions.md): why the commands look the way they do, and how we work.
4. The owner's notes, each with a `.claude.md` companion that says what the code does today:
   [db.md](db.md) (the store), [mapper.md](mapper.md) (the mapper and its menu), [minis.md](minis.md),
   [models.md](models.md), [privacy.md](privacy.md).
5. [examples.md](examples.md): worked tables and queries for Gmail, Drive and WhatsApp.
6. [from-io.md](from-io.md): what came from the io repo, and where the evidence is.

For agents: [handoff.md](handoff.md).

`*.md` files are the owner's; `*.claude.md` files are local, gitignored drafts by Claude for the owner to read and fold in.

For the Signal pilot, see [alpha onboarding and acceptance checks](signal-alpha.md).
