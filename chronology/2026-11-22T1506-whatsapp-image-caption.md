# The phone supplied the missing reference

A screenshot of the phone's Jam Buns search gave us the date, caption and destination of the Young Birders’ Month post. We verified the same image record on the DGX. The benchmark had discarded its caption because it retained only plain chat messages. Adding just the cached caption text made the user's “birding” paraphrase work with the existing Drive embedder.
