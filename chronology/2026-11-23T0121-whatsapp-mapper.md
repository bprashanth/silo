# Picking the result set mattered as much as building it

On the twelve new lookups, the private hybrid probe found all reference records. Giving the normal mapper a plain ranked view delivered two; giving it source counts and the bound group delivered eight. On the earlier multi-message cases the same menu did much worse. Unknown groups, counts and short sender names still produced unsupported results. Reverse-order repeats and the preview diagnostic are being checked separately.
