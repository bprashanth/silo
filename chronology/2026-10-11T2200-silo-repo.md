# musings becomes the silo repo

- **The rename.** The directory `musings` was renamed to `silo` and made the repo
  `github.com/bprashanth/silo`. The bot was stopped, moved and restarted from the new path.
  An end-to-end check through Telegram (`tl_session.py`: `/reset`, then the NGO workbook
  with "total actual expenditure Apr–Sep 2025") answered ₹19,080,600, which matches the workbook.
- **Bridge config is now environment variables** (`TELEGRAM_BOT_TOKEN`, `OPENROUTER_API_KEY`,
  `IDLI_BASE_URL`, `IDLI_MODEL`, `TG_ALLOWED`), with a fallback to json files in
  `$SILO_CONFIG` (default `~/.config/silo`).
  - On this box, `~/.config/silo` symlinks the existing files in `~/.config/idlisseus`.
  - Without an OpenRouter key, the external models disappear from `/model`, so an
    install with no key can't send data off the box.
  - The greeting now says "Silo" instead of "Io".
- **`tg-bridge/start.sh`** builds the venv and the sandbox image if they're missing, warns
  about a missing model server or an empty allowlist, and (re)starts the bot.
  `requirements.txt` pins the venv.
- **New docs:**
  - `docs/deployment.md`: bringing the bridge up against an already-running local model.
  - `proposals/correctness-receipt.md` and `proposals/audit-checker.md`: the two "trustable"
    pieces, built on the harness-compare results.
- **io is referenced, not copied.** The bridge uses nothing from io. Only
  `benchmarks/harness-compare` needs `../io`, for its Codex binary, runtime and `writeConfig`
  (about 3.6 GB).
